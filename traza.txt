(d) Explicación de la diferencia y condición de igualdad

foldr y foldl producen resultados distintos porque tienen asociatividades
opuestas: foldr asocia a la derecha, agrupando los paréntesis como
d1 - (d2 - (d3 - (d4 - 0))), mientras que foldl asocia a la izquierda,
agrupando como (((0 - d1) - d2) - d3) - d4. Puesto que la resta (-) no es una
operación asociativa ((x - y) - z /= x - (y - z)), el cambio en el orden de
evaluación altera el valor final.

Para garantizar que foldr op z xs == foldl op z xs para cualquier lista
finita xs, se deben cumplir dos condiciones:

    Asociatividad: la operación op debe ser asociativa, es decir:

    (x op y) op w == x op (y op w)   para todo x, y, w.

    Elemento neutro: el valor inicial z debe ser neutro tanto por la
    izquierda como por la derecha para la operación op:
    z op x == x   y   x op z == x        para todo x.
    En términos algebraicos, esto equivale a que la estructura formada por el
    tipo de los elementos, la operación binaria op y el elemento neutro z
    constituya un monoide (por ejemplo, (+) con 0, (*) con 1, o (++) con []).
